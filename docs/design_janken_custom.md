# 課題1 設計書：じゃんけんアプリのカスタマイズ（`feature/janken-custom`）

## 1. 目的と変更範囲
講義資料 `08-03` で作成したじゃんけんアプリの基本構造・通常モードの挙動を維持したまま、課題1の2つの機能を追加する。

1. **課題1-1：接待モードの追加**
   - 入力フォーム（`templates/janken_form.html`）にチェックボックス（`id="is_settai"`, `name="is_settai"`, `value="on"`）を追加する。
   - `is_settai` が ON の場合、プレイヤーの手（`hand`）が未選択（後出し）であっても `"rock"`（グー）として扱い、CPU の手（`cpu`）にはプレイヤーが必ず勝つ手（`rock` → `scissor`, `scissor` → `paper`, `paper` → `rock`）を設定する。
2. **課題1-2：プレイヤー勝利時の赤文字表示**
   - プレイヤーが勝利した場合のみ `is_win = True` をテンプレート（`templates/janken_play.html`）へ渡し、結果メッセージ（`<h2>`）を赤文字で表示する。

## 2. 既存機能への影響分析（非干渉確認）
| ケース | `is_settai` | `hand` | 期待される挙動 | 影響 |
| :--- | :--- | :--- | :--- | :--- |
| 通常・手選択あり | `None` (OFF) | `"rock"` / `"scissor"` / `"paper"` | CPU はランダム。勝ちのみ赤文字、あいこ・負けは通常色 | 既存の勝敗ロジックを維持 |
| 通常・手未選択（後出し） | `None` (OFF) | `None` | 「後出しはダメです。」（通常色）、プレイヤー画像は `mark_batsu.png` | 既存の後出し判定を維持 |
| 接待・手選択あり | `"on"` (ON) | `"rock"` / `"scissor"` / `"paper"` | CPU は必ず負ける手を選択し、「〇〇の勝ち」（赤文字） | 新規追加 |
| 接待・手未選択（後出し） | `"on"` (ON) | `None` → `"rock"` に補正 | プレイヤーはグー画像（`janken_gu.png`）、CPU はチョキ（`scissor`）、「〇〇の勝ち」（赤文字） | 新規追加 |
| 名前が空白のみ | 任意 | 任意 | `.strip()` により空文字とみなし `"名無しさん"` にフォールバック | 境界ケースの改善 |
