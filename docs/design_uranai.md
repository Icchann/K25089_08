# 課題2 設計書：占いアプリの作成（`feature/uranai`）

## 1. 目的と仕様要件
既存のじゃんけんアプリ（`/janken`, `/janken/play`）と同じプロジェクト内に、互いに干渉しない形で占いアプリ（`/uranai`, `/uranai/play`）を追加する。

### ルーティング仕様
- `GET /uranai`: 生年月日（`birthday`）と名前（`name`）を入力するフォーム（`templates/uranai_form.html`）を表示する。送信ボタンは「占う」。
- `POST /uranai/play`: 入力データを受け取り、5段階の占い結果とメッセージ（`templates/uranai_play.html`）を表示する。

### 計算アルゴリズム仕様
1. 現在日付を `yyyyMMdd` 形式の整数に変換する（例：`20261116`）。
2. 生年月日（`YYYY-MM-DD`）を `yyyyMMdd` 形式の整数に変換する（例：`20050401`）。
3. 減算結果の絶対値を求める：`diff = abs(today_int - birth_int)`
4. 名前の文字数との積を求める：`product = diff * len(name)`
5. 5で割った余りをインデックスとして `URANAI_RESULTS_TABLE = (5, 1, 3, 2, 4)` から占い結果（`1`〜`5`）を取得する：`rank = URANAI_RESULTS_TABLE[product % 5]`

### バリデーション・入力不備時の仕様
以下のいずれかに該当する場合は、占い結果（段階）を **`1`** とし、メッセージを **「`入力不備で占えませんでした`」** とする：
- 生年月日が未入力（空文字または `None`）
- 生年月日のデータ形式が日付に変換できない（`YYYY-MM-DD` の10文字でない、または `datetime.strptime(birthday_str, "%Y-%m-%d")` で `ValueError` となる不正文字列・非実在日付）
- 名前が未入力（前後空白を `.strip()` した結果が空文字になるケースを含む）

## 2. 既存機能（じゃんけんアプリ）への非干渉設計
- CSS は `static/janken.css` を変更せず、占い専用の `static/uranai.css` に分離することでじゃんけん画面のレイアウトへの副作用をゼロにする。
- `main.py` では占い計算を純粋関数 `evaluate_uranai(name_raw, birthday_raw, today_int=None)` として分離し、日付を固定した単体テスト（講義資料の具体例 `20261116` / `20050401` / `"愛工太郎"` → 結果 `5`）と HTTP エンドポイントテストの両方で検証可能にする。

## 3. UI・視覚表現の独自設計（サンプルとの差別化）
- サンプルの星マーク（☆）表現は使用せず、**5段階の運勢メーター（プログレスゲージバー：20%〜100%）** と **運勢ランクバッジ（段階別の配色とラベル）** を組み合わせたカードUIで表現する。
