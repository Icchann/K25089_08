# 第8回個人課題：じゃんけんアプリ＆占いアプリ

## 1. 動作確認方法
1. プロジェクトディレクトリで以下を実行してサーバーを起動します。
   ```bash
   $ pyenv local 3.14.4
   $ python main.py
   ```
2. ブラウザで `http://localhost:8888/` にアクセスします。
   - じゃんけんアプリ: `http://localhost:8888/janken`
   - 占いアプリ: `http://localhost:8888/uranai`
3. 単体テストを実行する場合は以下を実行します。
   ```bash
   $ python tests/test_janken.py -v
   $ python tests/test_uranai.py -v
   ```

## 3. デザイン・実装で工夫したポイント
- **サンプルと差別化した独自の視覚表現（運勢メーター＆段階別テーマ配色）**:
  - 星記号（☆）による表現ではなく、占い結果（1〜5）に応じてゲージ幅（20%〜100%）と配色テーマ（ゴールド・エメラルド・ブルー・バイオレット・スレート、入力不備時はレッド）が変化するプログレスメーターと5段階ステップインジケータを `static/uranai.css` で実装しました。
- **既存機能（じゃんけんアプリ）への非干渉設計と責務分離**:
  - じゃんけんアプリの基本構造（`08-03`）と `static/janken.css` を維持したまま、占いアプリ専用のスタイルシート `static/uranai.css` および純粋関数 `evaluate_uranai()`・`parse_birthday_to_int()` を分離して実装しました。
  - 各機能の追加にあたって設計書（`docs/design_janken_custom.md`, `docs/design_uranai.md`）を作成し、影響範囲と境界ケースを整理しました。
- **境界ケースを考慮した入力バリデーションと自動テスト**:
  - 名前入力で空白スペースのみ（`"   "`）が送信された場合も `.strip()` により未入力として扱うようにしました。
  - 生年月日は `YYYY-MM-DD` 形式の桁数と `datetime.strptime()` による実在日付検証を組み合わせ、未入力や不正日付（`2026-02-30` など）の場合に確実に結果 `1`・メッセージ「`入力不備で占えませんでした`」を返すよう実装し、`unittest`（`tests/test_janken.py`, `tests/test_uranai.py`）で全パターンを自動検証しました。
